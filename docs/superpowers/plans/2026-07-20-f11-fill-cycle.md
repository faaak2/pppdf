# F11 Three-Stage Fill Cycle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** F11 cycles `normal → height-fit → fill → normal`: the new middle stage sizes the window to the work-area height at the current page's (rotated) aspect ratio, snapped flush to the nearest screen edge.

**Architecture:** Pure rect math goes in `layout.rs` (no OS types there — plain `i32` tuples), a tiny public aspect accessor on `App`, and the OS shim `window.rs` rewires its existing `toggle_fill` into a three-arm cycle driven by a new `FillStage` enum beside the existing `saved_rect`. Spec: `docs/superpowers/specs/2026-07-20-f11-fill-cycle-design.md`.

**Tech Stack:** Rust, windows crate (Win32), existing pppdf test harness (`cargo test` unit tests; OS-shim behavior covered by `docs/manual-tests.md`).

## Global Constraints

- Help copy, verbatim everywhere it appears: `Fit screen height / fill / restore` (d2d.rs F1 row and README row).
- `layout.rs` allows **no OS types** — the new function takes/returns `(i32, i32, i32, i32)` tuples `(left, top, right, bottom)` in physical px.
- Height/width basis is the monitor **work area** (`mi.rcWork`), never `rcMonitor`.
- Nearest-edge tie (window center exactly at the work-area midpoint) snaps **LEFT**.
- Width is clamped to the work-area width; no width floor in the math (the existing `WM_GETMINMAXINFO` `MIN_SIZE_DIP` guard covers the narrow end).
- No document / zero pages: F11 keeps today's two-state behavior (fill ↔ restore); the height-fit stage is skipped.
- The cycle state changes **only on F11** — no live re-fit on page turn, rotation, doc load, or manual move/resize.
- Every change must pass `cargo build` and `cargo test` both **with and without** `--features pro`.

/// F11 height-fit: the work-area-height rect at `aspect` (page w/h, rotation
/// already applied), flush against the work-area edge nearest to
/// `cur_center_x` (tie: left). Width clamps to the work width; aspect <= 0
/// (no page) degenerates the same way. No width floor here — the window's
/// WM_GETMINMAXINFO guard covers the narrow end. Tuples are
/// (left, top, right, bottom) in physical px.
pub fn height_fit_rect(
    work: (i32, i32, i32, i32),
    aspect: f32,
    cur_center_x: i32,
) -> (i32, i32, i32, i32) {
    let (wl, wt, wr, wb) = work;
    let work_w = (wr - wl).max(0);
    let h = (wb - wt).max(0);
    let want = if aspect > 0.0 { (h as f32 * aspect).round() as i32 } else { work_w };
    let w = want.min(work_w);
    let mid = wl + work_w / 2;
    let left = if cur_center_x <= mid { wl } else { wr - w };
    (left, wt, left + w, wb)
}
```

(Float-to-int `as` casts saturate in Rust, so an absurd aspect can't overflow — it clamps to `work_w`.)

    /// Aspect (width/height) of the current page as displayed — rotation
    /// applied. None when no document is open or it has no pages; F11's
    /// height-fit stage keys off that None.
    pub fn page_aspect(&self) -> Option<f32> {
        match &self.mode {
            Mode::Doc(d) if d.pages > 0 => {
                let (w, h) = d.page_pt_rot();
                Some(w / h)
            }
            _ => None,
        }
    }
```

- [ ] **Step 3: Rewrite `toggle_fill`**

Replace the whole function (window.rs:1566-1604, doc comment included) with:

```rust
    /// F11 cycles the window through three stages: height-fit (work-area
    /// height at the current page's rotated aspect, flush at the nearest
    /// screen edge), fill (work area edge to edge, taskbar visible), then
    /// back to the size/position saved when the cycle started. Without a
    /// document there is no aspect: height-fit is skipped and F11 stays the
    /// old two-state fill/restore. Independent of native maximize (Win+Up).
    fn toggle_fill(&mut self) {
        unsafe {
            if self.fill_stage == FillStage::Filled {
                self.fill_stage = FillStage::Normal;
                if let Some(saved) = self.saved_rect.take() {
                    let _ = SetWindowPos(
                        self.hwnd,
                        None,
                        saved.left,
                        saved.top,
                        saved.right - saved.left,
                        saved.bottom - saved.top,
                        SWP_NOZORDER | SWP_NOACTIVATE,
                    );
                }
                return;
            }
            let mut rc = RECT::default();
            let _ = GetWindowRect(self.hwnd, &mut rc);
            let monitor = MonitorFromWindow(self.hwnd, MONITOR_DEFAULTTONEAREST);
            let mut mi = MONITORINFO {
                cbSize: core::mem::size_of::<MONITORINFO>() as u32,
                ..Default::default()
            };
            if !GetMonitorInfoW(monitor, &mut mi).as_bool() {
                return; // no monitor info: stay in the current stage
            }
            let w = mi.rcWork;
            if self.fill_stage == FillStage::Normal {
                self.saved_rect = Some(rc);
                if let Some(aspect) = self.app.page_aspect() {
                    let (l, t, r, b) = crate::layout::height_fit_rect(
                        (w.left, w.top, w.right, w.bottom),
                        aspect,
                        rc.left + (rc.right - rc.left) / 2,
                    );
                    self.fill_stage = FillStage::HeightFit;
                    let _ = SetWindowPos(
                        self.hwnd,
                        None,
                        l,
                        t,
                        r - l,
                        b - t,
                        SWP_NOZORDER | SWP_NOACTIVATE,
                    );
                    return;
                }
                // No document: skip height-fit, fall through to fill.
            }
            self.fill_stage = FillStage::Filled;
            let _ = SetWindowPos(
                self.hwnd,
                None,
                w.left,
                w.top,
                w.right - w.left,
                w.bottom - w.top,
                SWP_NOZORDER | SWP_NOACTIVATE,
            );
        }
    }
```

Notes that must survive implementation:
- `saved_rect` is written **only** in the `Normal` arm — a press from `HeightFit` must not overwrite it, or restore would return to the height-fit rect instead of the user's original.
- `GetMonitorInfoW` failure returns **before** saving or advancing (parity with today: nothing changes).
- `Filled → Normal` with `saved_rect == None` cannot normally happen (the arm that sets `Filled` always ran the `Normal` arm first, which saves) — the `if let` just makes it a harmless stage reset.
